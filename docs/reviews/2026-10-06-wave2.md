## 2. Verified-good controls (regression-pinned)

1. **Token**: constant-time compare, deny-if-unconfigured, 401 on every REST
   endpoint, never echoed into frames/logs/journal (sentinel-proven).
2. **Role capabilities**: full §4 matrix enforced server-side (36 parametrized
   cases) + receive-side fan-out (speak → body+ui, orb_state → ui, act_req →
   body-only).
3. **Limits**: 40 text msgs/s, 125 binary/s, 8 MiB cap, 3-strike malformed
   close — all `E_RATE_LIMIT`/`E_BAD_MSG` + disconnect, as §1.
4. **Confirmation**: timeout-abort (never auto-approve), deny → "Aborted." +
   `E_CANCELLED`, approve → `confirm_granted` journaled per job, concurrent
   confirms isolated, ambiguous text fails closed.
5. **Private Mode**: zero provider HTTP (counting mock), fastpath preserved,
   mode-as-overlay, private-check ordered before the provider call (source
   pin).
6. **cloud_temp**: no ollama/go in chain, `local_model.enabled: false`, zero
   ollama-URL traffic under a full job, local code paths still present for
   Wave 6.
7. **Isolation**: `RAPHAEL_INSTANCE` forced in the suite; two real brain
   subprocesses on ephemeral ports — separate tokens (cross-401 proven),
   separate job stores, zero cross-talk; MAIN's pidfile never written from
   tests (guard in conftest + subprocess bootstrap).
8. **Core Guard**: `confirm.py`/`auth.py`/`control.py`/`mode.py` pinned
   byte-stable by manifest (`tests/core_guard.py`) + semantic tripwires
   (fail-closed text, constant-time compare, kill_gui momentary, private
   before plan).
9. **Ownership**: merge-loop checker (`tests/ownership_check.py`, 39 cases
   against the live OWNERSHIP table) — the diff-vs-lane gate the integrator
   asked for.
10. **No-placeholder replies**: reply text delivered verbatim from provider →
    job_event/speak/subtitle; provider-down line is the documented sentence.
