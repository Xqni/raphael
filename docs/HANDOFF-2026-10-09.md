## 4. Process law (abbreviated — read AGENT_RULES.md for the real thing)

- **Merge order** is fixed (WAVES.md). A `wave_done` without a linked green
  CI run id is bounced (QA-4). Ownership is enforced by
  `tests/ownership_check.py` + `docs/OWNERSHIP.md`; grants are recorded in
  `tests/ownership_exceptions.txt`.
- **Core Guard**: `tests/core_guard_manifest.json` pins hashes of
  control-plane files; changing them requires
  `python3 tests/core_guard.py --update --approval <request-doc>` — CI fails
  otherwise. Never pin from a dirty worktree (that incident cost us a red
  streak).
- **Personal data**: `python3 scripts/scan_personal.py --strict` gates CI
  (FAIL-severity only; REVIEW is advisory by 2026-10-08 decision).
  Placeholders: `<wsl-user>`, `<win-user>`, `<gh-owner>`, `<repo-root>`.
- **Secrets**: nothing secret lives in this repo. `.env` is gitignored;
  tokens are injected at runtime. Never commit a key.
- **Coord bus** (events/cursors/inbox for the 10 lanes) lives outside git in
  `~/.raphael-coord/`; `tools/conductor/coord.py` is the CLI.
